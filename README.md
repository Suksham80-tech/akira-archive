# AKIRA // ARCHIVE

**AKIRA // ARCHIVE** is an offline-first, neo-brutalist web application for searching, triaging, and tracking your personal anime watchlist using a built-in local directory of **38,000+ anime titles**—no live API rate limits, network lag, or account lock-in.

## ✨ Features
* **38,000+ Local Anime Directory:** Instant, zero-latency client-side search powered by a bundled JSON dataset sourced from an open-source GitHub anime database.
* **Three-Tier Triage System:** Quickly categorize shows into **Watched**, **Maybe Later**, or **Rather Not** to keep your backlog organized.
* **Manual Entry Support:** Add custom titles, newly aired shows, or unlisted entries directly via a built-in modal.
* **Neo-Brutalist UI:** High-contrast crimson, cream, and black aesthetic engineered for fast scanning and zero visual clutter.
* **100% Offline & Zero-Backend:** Built purely with vanilla HTML, CSS, and JavaScript—runs locally in any browser with zero external API dependencies.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Data Source:** Local static JSON directory (38,000+ entries from open-source GitHub anime database)
* **Storage:** Browser `localStorage`

## 🚀 Getting Started
1. Clone or download this repository.
2. Open `index.html` using a local server (such as **VS Code Live Server** or `python -m http.server`) so the browser can load the local JSON dataset cleanly.
3. Search across 38,000+ titles and start building your archive.
